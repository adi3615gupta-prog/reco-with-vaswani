<objective>
Implement an immutable, persistent audit trail architecture for practitioner override actions (Manual Match, Force Match, Unlink Match, Party Auto-Match) satisfying statutory compliance requirement `AUDIT-01`. Create a dedicated SQLite table `reconciliation_audit_log` in `network_data.db`, expose validated Express REST endpoints via `audit_trail_routes.js` mounted in `server.js` per D-02 and D-03, build an offline-resilient client sync service (`src/lib/auditTrailService.ts`) per D-04, replace silent UI mutations with an interactive `AuditJustificationModal.tsx` in `PartyWiseReport.tsx` and `ResultsTable.tsx` per D-05, and integrate an unmerged `Audit Trail` tab in `masterExport.ts` and `partyWiseExport.ts` per D-06 and `CORE-01`.

Purpose: Provide legally defensible practitioner audit trails, eliminate silent data alterations, preserve prior calculation state, ensure offline availability, and produce compliant Zero-Merge Excel audit reports.
Output: Backend audit routes and schema, frontend offline sync service, interactive justification modal, counterparty & results table UI integration, Zero-Merge Excel export sheet, and automated test suite.
</objective>

         - Creates `AuditOverrideRecord` with generated UUID, client timestamps, `is_synced: false`.

         - Dispatches async fetch to `POST /api/audit/reconciliation-override`. If response is 201/200, updates local record `is_synced: true`. If network fails, catches gracefully and leaves in queue.
         - Returns the created record.
       - `syncPendingAuditLogs(): Promise<number>`:
         - Retrieves unsynced entries from `localStorage`.
         - Batches POST requests to backend.
         - Updates status to `is_synced: true` upon success.
         - Registers `window.addEventListener('online', () => syncPendingAuditLogs())`.
       - `getOverrideLogs(companyName?: string): Promise<AuditOverrideRecord[]>`:
         - Attempts `GET /api/audit/reconciliation-override` with fallback to local unsynced queue.
