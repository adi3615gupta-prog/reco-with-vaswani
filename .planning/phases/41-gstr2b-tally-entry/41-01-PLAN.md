         id TEXT PRIMARY KEY,
         client_gstin TEXT NOT NULL,

         return_period TEXT NOT NULL,
         section TEXT DEFAULT 'B2B',
         supplier_gstin TEXT NOT NULL,

<task type="auto">
  <name>Task 2: Core 2B-to-Tally Conversion Engine</name>
  <files>src/lib/gstr2bTallyEngine.ts, src/test/gstr2bTallyEngine.test.ts</files>
  <action>
1. Create `src/lib/gstr2bTallyEngine.ts`:
   - `deriveGstRate(txval, igst, cgst, sgst)`: Computes effective tax percentage (e.g. 18%, 12%, 5%, 28%, 0%).
   - `derivePurchaseLedgerName(rate, isInterstate)`: Returns rate-wise purchase ledger, e.g.:
     - `Purchase @ 18%`, `Purchase @ 12%`, `Purchase @ 5%`, `Purchase @ 28%`, or `Purchase Exempted` (rate 0).
   - `convert2bInvoicesToTallyVouchers(invoices, options)`:
     - For `B2B` / `B2BA`:
       - `voucherType`: `'Purchase'`
       - Credit Party Leg: `ledgerName: invoice.supplier_name || invoice.ctin`, `amount: +total_val`
       - Debit Purchase Leg: `ledgerName: derivePurchaseLedgerName(rate)`, `amount: -txval`
       - Debit CGST Leg: `ledgerName: 'Input CGST'`, `amount: -cgst` (if `cgst > 0`)
       - Debit SGST Leg: `ledgerName: 'Input SGST'`, `amount: -sgst` (if `sgst > 0`)
       - Debit IGST Leg: `ledgerName: 'Input IGST'`, `amount: -igst` (if `igst > 0`)
       - Debit Cess Leg: `ledgerName: 'Input Cess'`, `amount: -cess` (if `cess > 0`)
       - Round Off Leg: Auto-added if sum has decimal rounding discrepancy.
     - For `CDNR` / `CDNRA`:
       - `voucherType`: `'Debit Note'`
       - Debit Party Leg: `ledgerName: invoice.supplier_name || invoice.ctin`, `amount: -total_val`
       - Credit Purchase Leg: `ledgerName: derivePurchaseLedgerName(rate)`, `amount: +txval`
       - Credit CGST/SGST/IGST/Cess Legs with positive values (reversal).
       - Round Off Leg: Auto-added if sum has decimal rounding discrepancy.
   - `extractMasterLedgersFrom2b(invoices)`:
     - Generates `MasterLedger[]` entries for each unique supplier party under `parentGroup: 'Sundry Creditors'`, with address, state, and GSTIN.
2. Create unit tests in `src/test/gstr2bTallyEngine.test.ts` verifying:
   - Correct GST rate detection and rate-wise ledger names.
   - Math equilibrium ($Dr + Cr = 0$) for B2B and CDNR entries.
   - Correct deemed positive / negative amounts matching Tally XML conventions.
  </action>
</task>
