# Plan 18-01: 4-Digit Taxonomy (1001-4902), Dual-Mode Storage Engine, Level I-IV AS Matrix & Tally/Excel Ingestion

## Goal
Implement the data and ingestion foundation for Module 1.6 Financial Statements Engine:
1. Complete 4-Digit Group Taxonomy dictionary (1001–4902) mapping Schedule III Division I/II and Non-Corporate line items.
2. Dual-mode Client Configuration & Storage Engine (`src/lib/finStatements.types.ts`, `src/lib/finStatements.storage.ts`, `src/lib/finStatements.seed.ts`) supporting both Corporate (Company) and Non-Corporate entities.
3. ICAI June 2022 Technical Guide Level I–IV Entity Classification & AS Applicability Matrix.
4. Intelligent Trial Balance Ingestion (Excel/CSV and Tally XML on port 9000) with confidence-scored auto-mapping suggestions based on Tally primary groups.
5. Unit tests validating taxonomy completeness, Level I–IV classification logic, and Tally ingestion accuracy.

## Tasks

- [x] **Task 1: Expand Data Models & Master 4-Digit Taxonomy (`src/lib/finStatements.types.ts`)**
  - Update `MasterGroupCode` with 4-digit code range (1001 to 4902), Schedule III category, statement type (`BS`, `PL`, `CFS`, `R_DISC`), note reference, and guidance note references (e.g. GN 8.1.3, GN 8.2.1, GN 9.8).
  - Add entity mode types: `entity_type: 'corporate' | 'non_corporate'`, with sub-types: `'pvt_ltd' | 'ltd' | 'opc' | 'proprietorship' | 'partnership' | 'llp' | 'trust'`.
  - Add Level I–IV classification models: `LevelClassification: { level: 'Level I' | 'Level II' | 'Level III' | 'Level IV', turnover: number, borrowings: number, exemptions: string[] }`.
  - Add data structures for Partners' Capital accounts (2 to 50 partners), 17 MCA Regulatory Disclosures (`R_Disc`), and 11 Financial Ratios.

- [x] **Task 2: Implement Complete 4-Digit Seed Dictionary & Storage Engine (`src/lib/finStatements.seed.ts`, `src/lib/finStatements.storage.ts`)**
  - Populate the full verified dictionary of ~120 group codes (1001 to 4902) extracted from `Group Codes.pdf` and `Drop_List` sheet.
  - Implement the ICAI June 2022 Technical Guide Level I–IV classification evaluator function:
    - Level I: Turnover $> ₹250$ Cr or Borrowings $> ₹50$ Cr.
    - Level II: Turnover $> ₹50$ Cr or Borrowings $> ₹10$ Cr.
    - Level III: Turnover $> ₹10$ Cr or Borrowings $> ₹2$ Cr.
    - Level IV: Turnover $\le ₹10$ Cr and Borrowings $\le ₹2$ Cr.
    - Evaluates AS-1 to AS-29 applicability (AS-3, AS-17, AS-18 exemptions, etc.).
  - Implement localStorage & IndexedDB persistence with multi-client scoping and auto-backup.

- [x] **Task 3: Intelligent Trial Balance Ingestion & Tally Mapping Engine (`src/components/finstatements/TBImportMapping.tsx`, `src/lib/tallyApi.ts`)**
  - Support Excel/CSV dropzone and direct Tally XML / ODBC ingestion (`SELECT $Name, $Parent, $_PrimaryGroup, $_ClosingBalance FROM TallyUser.Ledger`).
  - Auto-mapping heuristic: Map Tally `$_PrimaryGroup` (e.g. "Sundry Creditors" $\to$ 1702/1701, "Duties & Taxes" $\to$ 1810/2904, "Bank Accounts" $\to$ 2803, "Sales Accounts" $\to$ 3001) with confidence percentage.
  - Automatic zero-balance suppression, debit/credit imbalance detector, and negative balance flagger.

- [x] **Task 4: Unit Testing & Invariant Verification (`src/test/finStatementsTaxonomy.test.ts`)**
  - Verify all 4-digit codes from 1001 to 4902 resolve correctly.
  - Test Level I–IV classification with boundary values (e.g., ₹249.99 Cr vs ₹250.01 Cr, ₹49.99 Cr vs ₹50.01 Cr).
  - Test Trial Balance auto-mapping rules on sample Tally ledger data.
