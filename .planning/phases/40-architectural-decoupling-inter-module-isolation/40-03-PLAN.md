  <files>src/hooks/useScopedTallySession.ts</files>
  <action>
1. Create `src/hooks/useScopedTallySession.ts`:
   - Accepts `moduleKey: string` (e.g. `'tds'`, `'cma'`, `'clause44'`, `'fin-statements'`, `'tally-xml'`) and initial port (default 9000).
   - Manages state: `port`, `setPort`, `status: 'disconnected' | 'connecting' | 'connected' | 'error'`, `companyInfo`, `errorMessage`.
   - Methods: `connect()`, `disconnect()`, `ping()`.
   - Uses `useEffect` cleanup return function:
     ```ts
     useEffect(() => {
       return () => {
         // Immediate teardown on component unmount / navigating away from module
         disconnect();
         clearTallyMetadataCache();
       };
     }, [moduleKey]);
     ```
   - Guarantees that connection state is 100% ephemeral and scoped strictly to that module's lifecycle.
