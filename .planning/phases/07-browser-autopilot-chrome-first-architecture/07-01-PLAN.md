<task id="1" name="Create Centralized Chrome-First Browser Launcher Module">
Create `gstr2b/browserLauncher.js` with `launchAutopilotBrowser(chromiumEngine, customOptions)`:
1. Define standardized launch arguments: `--start-maximized`, `--disable-blink-features=AutomationControlled`, `--no-sandbox`, `--no-first-run`, `--no-default-browser-check`, `--disable-infobars`, `--disable-extensions`.
2. Inspect Windows candidate paths for `chrome.exe` (`C:\Program Files\Google\Chrome\Application\chrome.exe`, `C:\Program Files (x86)\...`, `%LOCALAPPDATA%\...`).
3. Priority Cascade:
   - Priority 1: Launch via `channel: 'chrome'` (or explicit `executablePath` if found).
   - Priority 2: Launch via standard bundled Chromium `chromiumEngine.launch(options)`.
   - Priority 3: Fallback to Microsoft Edge via `channel: 'msedge'`.
4. Log verbose engine detection info (`[Browser Launcher] Successfully launched Google Chrome`).
5. Return `{ browser, engineType }`.
</task>
