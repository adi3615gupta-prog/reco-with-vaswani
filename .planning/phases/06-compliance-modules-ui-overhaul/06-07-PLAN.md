# Plan 06-07: Split Returns Autopilot & Ingestion Deck (Independent GSTR-1 & GSTR-2B Sync & Table 3.1 / Table 4 Injection)

## Objective
Split the unified Returns Auto-Pilot & Ingestion Deck into two independent, parallel operational cockpits:
1. **GSTR-1 Outward Supplies Deck:** Downloads or ingests GSTR-1 independently, previews sales breakdowns, and injects strictly into GSTR-3B Table 3.1.
2. **GSTR-2B Inward ITC Deck:** Downloads or ingests GSTR-2B independently, previews ITC breakdowns, and injects strictly into GSTR-3B Table 4.

## Background & Problem Analysis
Previously, `ReturnsAutoIngestDeck.tsx` combined both returns into a single action button and shared dropzone. However:
- GST Portal follows entirely different navigation paths and data structures for GSTR-1 and GSTR-2B.
- The single autopilot button only targeted `/api/gstr2b/portal-sync-browser` and never invoked `/api/gstr1/portal-sync-browser`.
- Ingestion errors in one return blocked the user from populating the other into the 3B working sheet.
- Practitioners need complete autonomy to download GSTR-1 (Sales), review and inject into Table 3.1, and separately download GSTR-2B (ITC), review and inject into Table 4.

## Proposed Architecture & UI Layout

### 1. Two-Column Split Cockpit Layout
Split the deck into two responsive side-by-side cards:

#### **Card A: GSTR-1 Outward Sales & Tax (Injects Table 3.1)**
- **Theme:** Blue/Indigo gradient styling (`border-blue-500/30`, `bg-blue-950/20`).
- **Autopilot Trigger:** Dedicated "Sync GSTR-1 Autopilot" button calling `POST /api/gstr1/portal-sync-browser`.
  - Independent loading state (`isGstr1Running`, `gstr1Step`).
- **Manual Upload:** Dedicated GSTR-1 file dropzone / file picker supporting GSTR-1 JSON or Excel.
- **Data Preview Deck:**
  - Total Outward Taxable Value
  - IGST, CGST, SGST breakdowns
  - Counts: B2B, B2C, Credit Notes, Exports
- **Action Control:**
  - Primary button: **"⚡ Inject into Table 3.1 (Outward)"**
  - Reset button: Clear GSTR-1 data for the month.
  - Live Status Pill: `Table 3.1 Synced` (Emerald) vs `Pending` (Slate).

#### **Card B: GSTR-2B Inward Supplies & ITC (Injects Table 4)**
- **Theme:** Emerald/Cyan gradient styling (`border-emerald-500/30`, `bg-emerald-950/20`).
- **Autopilot Trigger:** Dedicated "Sync GSTR-2B Autopilot" button calling `POST /api/gstr2b/portal-sync-browser`.
  - Independent loading state (`isGstr2bRunning`, `gstr2bStep`).
- **Manual Upload:** Dedicated GSTR-2B file dropzone / file picker supporting GSTR-2B JSON or Excel.
- **Data Preview Deck:**
  - Total Eligible ITC (IGST, CGST, SGST)
  - Inward RCM Liability
  - Supplier Credit Notes (ITC reduction)
  - Ineligible ITC
- **Action Control:**
  - Primary button: **"⚡ Inject into Table 4 (Eligible ITC)"**
  - Reset button: Clear GSTR-2B data for the month.
  - Live Status Pill: `Table 4 Synced` (Emerald) vs `Pending` (Slate).

### 2. Global Deck Controls (Header & Footer)
- **Financial Year Selector:** `2025-26` / `2026-27` pills with instant month context updates.
- **Master Quick Action:** **"Sync Both & Populate 3B"** shortcut button when practitioner wants 1-click end-to-end sync.
- **Auto-Hydrate from SQLite:** On client or month change, independently hydrate cached GSTR-1 and GSTR-2B summaries from local DB.

### 3. Engine Wiring (`src/lib/gstrAutoIngest.ts` & `src/pages/ReturnsDashboard.tsx`)
- Ensure `applyReturnsToAnnualWorking(workingData, month, gstr1, null)` cleanly updates only Table 3.1 without disturbing Table 4 ITC.
- Ensure `applyReturnsToAnnualWorking(workingData, month, null, gstr2b)` cleanly updates only Table 4 without disturbing Table 3.1 Sales.
- Ensure Rule 88A set-off cascade recalculates immediately after either injection.
