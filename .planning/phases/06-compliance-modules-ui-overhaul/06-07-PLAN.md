## 2. Split UI Architecture in `ReturnsAutoIngestDeck.tsx`

Refactor the single mixed card into **Two Distinct Operational Cards**:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│               ⚡ RETURNS AUTO-PILOT & INGESTION DECK (SPLIT ARCHITECTURE)               │
├───────────────────────────────────────────┬────────────────────────────────────────────┤
│   🟦 GSTR-1: OUTWARD SALES (TABLE 3.1)    │      🟩 GSTR-2B: INWARD ITC (TABLE 4)      │
├───────────────────────────────────────────┼────────────────────────────────────────────┤
│ • 🚀 Sync GSTR-1 Autopilot                │ • 🚀 Sync GSTR-2B Autopilot                │
│   (Target: /api/gstr1/portal-sync-browser)│   (Target: /api/gstr2b/portal-sync-browser)│
│ • 📁 Drag & Drop GSTR-1 (JSON/ZIP/Excel)  │ • 📁 Drag & Drop GSTR-2B (JSON/Excel)      │
│ • 📊 Live Sales & Tax Breakdown:          │ • 📊 Live Eligible ITC Breakdown:          │
│   B2B (₹20,018,168), B2C (₹491,948)       │   Eligible ITC (₹961,185), RCM (₹10,368)   │
│ • ⚡ [Inject to Table 3.1 (Outward)]      │ • ⚡ [Inject to Table 4 (Eligible ITC)]    │
│ • 🏷️ Status: Table 3.1 Synced / Pending   │ • 🏷️ Status: Table 4 Synced / Pending      │
└───────────────────────────────────────────┴────────────────────────────────────────────┘
```

1. **Independent Autopilot Actions:**
   - Card 1: `handleGstr1AutopilotSync()` $\rightarrow$ triggers `POST /api/gstr1/portal-sync-browser` with `{ gstin, returnPeriod, financialYear }`.
   - Card 2: `handleGstr2bAutopilotSync()` $\rightarrow$ triggers `POST /api/gstr2b/portal-sync-browser` with `{ gstin, returnPeriod, financialYear, portal_username }`.
2. **Independent File Ingestion:**
   - Card 1 has its own GSTR-1 file picker & dropzone.
   - Card 2 has its own GSTR-2B file picker & dropzone.
3. **Independent Injection Triggers:**
   - Card 1 Button: `onApplyIngestedReturns(activeGstr1, null)` $\rightarrow$ populates Table 3.1 only.
   - Card 2 Button: `onApplyIngestedReturns(null, activeGstr2b)` $\rightarrow$ populates Table 4 only.
   - Top Header Shortcut: `Sync Both & Populate 3B` when the practitioner wants a 1-click combined flow.
