# Plan 06-09: Promote Returns Preparation & Filing to Main Suite Hub with 5-Card Module Architecture

## Objective
Promote **04. Returns Preparation & Filing** from being nested inside the Work In Progress (WIP) suite to becoming a primary, first-class suite on the main page. Inside the Returns suite, construct a high-impact **5-card interactive navigation hub** (one dedicated card for each tab: GSTR-3B Working, 12-Month FY Matrix, GST IMS, GSTR-2B Downloader, GSTR-1 Downloader) while strictly preserving 100% of the underlying business logic, state management, and working functions.

---

## 1. Architectural Strategy

### A. Current Structure
- On the main dashboard (`activeCategoryCard === null`), there are 6 suites:
  - Suite 01: Work In Progress (WIP) Suite
  - Suite 02: Reconciliation Engine Hub
  - Suite 03: Data Collector & Connectors
  - Suite 04: Statutory Audit Modules
  - Suite 05: Taxation & Calculator Suite
  - Suite 06: Bank Ratio Analysis & CMA Credit Suite
- **04. Returns Preparation & Filing** is buried inside Suite 01 (WIP) as Module 1.4.
- In `ReturnsDashboard.tsx`, 5 submodules are toggled via an inline tab bar:
  1. `working3b`: GSTR-3B Working Sheet & Ingestion Deck
  2. `matrix`: 12-Month FY Comparative Matrix
  3. `ims2b`: GST IMS & 2B Manager (300+ Clients)
  4. `gstr2b_downloader`: GSTR-2B Downloader (Autopilot)
  5. `gstr1_downloader`: GSTR-1 Downloader (Autopilot)

### B. Target Structure
1. **Main Suite Grid (`activeCategoryCard === null` in `src/pages/Index.tsx` & `src/pages/Hub.tsx`)**:
   - Promote **Returns Preparation & Filing** as a prominent top-level Suite Card (Purple/Indigo theme).
   - Display a preview of its 5 modules:
     - `01. GSTR-3B Working`
     - `02. 12-Month FY Matrix`
     - `03. GST IMS Manager`
     - `04. GSTR-2B Downloader`
     - `05. GSTR-1 Downloader`
   - Remove "04. Returns Preparation & Filing" from the WIP Suite drill-down (`activeCategoryCard === 'wip'`).
   - Update WIP suite badge count from 8 to 7 modules.

2. **Dedicated Returns Suite Drill-Down (`activeCategoryCard === 'returns'`)**:
   - When the user opens the Returns Preparation suite, present **5 distinct, high-impact module cards**:
     - **Card 1: 01. GSTR-3B Working Sheet** (Blue theme, `Calculator` icon)
       - Subtitle: *Master Monthly Working & Rule 88A Cascade*
       - Highlights: Table 3.1 Outward & Table 4 Inward live set-off, auto-pilot injection deck, and official GSTN V5.8 portal JSON generator.
     - **Card 2: 02. 12-Month FY Matrix** (Teal theme, `Table` icon)
       - Subtitle: *Annual Comparative Tax Grid*
       - Highlights: April–March month-by-month comparative tax liability, ITC utilization, and cash outflow tracking.
     - **Card 3: 03. GST IMS (Invoice Management System)** (Amber theme, `Sparkles` icon)
       - Subtitle: *Inward Supplies Action Portal (300+ Clients)*
       - Highlights: Accept, Reject, or mark Pending inward B2B invoices & CDNR with portal sync and decision log.
     - **Card 4: 04. GSTR-2B Downloader (Autopilot)** (Emerald theme, `DownloadCloud` icon)
       - Subtitle: *1-Login 12M Autonomous Downloader*
       - Highlights: Single CAPTCHA 12-month loop download, non-blocking resilience, multi-period ingestion, and SQLite persistence.
     - **Card 5: 05. GSTR-1 Downloader (Autopilot)** (Indigo theme, `ArrowUpRight` icon)
       - Subtitle: *Autonomous Outward Sales Downloader*
       - Highlights: 12-month outward supplies consolidation, multi-period parsing, and full-year consolidated Excel.
   - Clicking any of the 5 cards triggers `setAppRoute('returns')` and automatically activates that specific tab (`returnsInitialTab`).

3. **`src/pages/ReturnsDashboard.tsx` Integration**:
   - Add `initialTab?: 'working3b' | 'matrix' | 'ims2b' | 'gstr2b_downloader' | 'gstr1_downloader'` to `ReturnsDashboardProps`.
   - Synchronize `activeTab` state with `initialTab`.
   - Upgrade the top navigation into an ergonomic 5-card high-density tab bar so users can switch seamlessly inside the dashboard.
   - **Zero Functional Regression**: All existing child components, event handlers, client vault, and calculations remain 100% intact.
