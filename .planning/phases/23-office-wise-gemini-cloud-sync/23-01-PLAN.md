# PLAN: 23-01 — Central Office-Wise Gemini Cloud Distribution & Firebase License Sync

**Phase:** 23 — Central Office-Wise Gemini Cloud Distribution  
**Plan:** 23-01  
**Status:** ✅ Completed  
**Depends on:** Phase 22 (Gemini backend & frontend)  
**Goal:** Ingest and synchronize the Gemini API Key centrally from Firebase Firestore (`reco-vaswani-license`), providing zero-config out-of-the-box AI assistant activation for all users in an office, with local SQLite caching and bidirectional admin sync.

---

## Tracer Slice (Ship First)

**Tracer:** A working `POST /api/gemini/sync-cloud` endpoint that queries Firestore (`serial_keys` where `office_id == currentOffice` or `system_config/ai_settings`), updates SQLite `app_config`, and activates Sourav AI without any manual key entry.

---

## Tasks

### T1 — Implement Firestore Cloud Sync Engine in `server.js` and `gemini_routes.js`
- **Files:** `server.js`, `gemini_routes.js`
- **Actions:**
  1. Add Firestore cloud key resolver helper `fetchCloudGeminiKey(firestore, officeId)`:
     - Check `serial_keys` where `office_id == officeId` and `key_type == 'server'` → read `doc.gemini_api_key`
     - If not found or empty, check `system_config/ai_settings` doc in Firestore → read `doc.gemini_api_key`
     - Return `{ apiKey, origin: 'cloud_office' | 'cloud_global' | null }`
  2. Integrate into `setupLicenseMonitoring` in `server.js`:
     - When `onSnapshot` fires on `serial_keys`, if `serverKeyDoc.gemini_api_key` is present, update SQLite `app_config` and log `[Gemini Cloud Sync]`.
  3. Call `syncCloudGeminiKey()` automatically on startup after `office_id` is resolved.

---

### T2 — Add `/api/gemini/sync-cloud` and `/api/gemini/push-cloud` in `gemini_routes.js`
- **File:** `gemini_routes.js`
- **Actions:**
  1. `POST /api/gemini/sync-cloud`:
     - Calls `fetchCloudGeminiKey(firestore, officeId)`
     - If found, writes to SQLite `app_config` (`gemini_api_key`, `gemini_key_origin`)
     - Returns `{ ok: true, configured: true, origin: 'cloud_office' | 'cloud_global' }`
  2. `POST /api/gemini/push-cloud`:
     - Body: `{ apiKey: string, scope: 'office' | 'global' }`
     - If `scope === 'office'`, updates `serial_keys` document where `office_id == officeId`
     - If `scope === 'global'`, updates/creates `system_config/ai_settings` document with `{ gemini_api_key, updated_at }`
     - Returns `{ ok: true, message: 'Gemini key pushed to Firebase cloud successfully' }`
  3. Update `GET /api/gemini/status`:
     - Returns `{ configured: boolean, origin: 'cloud_office' | 'cloud_global' | 'local_manual' | 'env' | null }`
