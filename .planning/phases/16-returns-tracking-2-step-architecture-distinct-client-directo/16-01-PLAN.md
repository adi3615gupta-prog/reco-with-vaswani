# Plan 16-01: Returns Tracking 2-Step Architecture (Distinct Client Directory Gateway & Scoped Detail Workspace)

## Goal
Establish a 2-step workflow for Submodule `06. Returns Tracking` (`ReturnsTrackingMaster.tsx`):
1. **Page 1 (Step 1):** Distinct client directory where every firm client is listed as a single distinct row (NOT repeated for every month) with search, status filters, multi-select checkboxes, and compliance progress pills.
2. **Page 2 (Step 2):** Scoped compliance cockpit displaying detailed month-by-month return filings, ARNs, and statutory KPIs strictly for the clients selected on Page 1, with a 1-click return button (`← Select Clients`) to adjust scope at any time.

---

## Task Breakdown

### Task 1: Step 1 Distinct Client Directory Gateway Implementation - [DONE]
- **File**: `src/components/ReturnsTrackingMaster.tsx`
- **Actions**:
  1. Implemented `uniqueClients` aggregation memo to group all raw return records into single distinct client entities:
     - `name`: Client Trade Name / Firm Name
     - `gstin`: GSTIN with state code
     - `frequency`: Statutory filing frequency (`Monthly` vs `QRMP`)
     - `filedCount` & `pendingCount`: Cumulative filings completed vs pending in FY
     - `overdueCount`: Number of overdue returns triggering late fees
     - `totalDue`: Total return obligations in FY (24 for Monthly)
     - `totalCashPaid`: Total PMT-06 cash tax paid in FY
  2. Implemented `directorySearch` & `directoryFilter` states with `filteredDirectoryClients` memo supporting:
     - Live search across trade name, legal entity, and GSTIN.
     - Category filter chips: `All Clients`, `Selected`, `Pending Filings`, `Monthly`, `QRMP`.
     - Bulk action triggers: `Select Visible`, `Clear All`, and `Track All Practice Clients`.
  3. Built Step 1 Directory View:
     - Header with Step 1 of 2 indicator, FY selector, and `Proceed to Dashboard` CTA.
     - 4 Directory KPI summary cards (Practice Directory total, Selected for Tracking, With Pending/Overdue, Fully Compliant).
     - Directory Table:
       - Column 1: `SELECT` with master checkbox in header and `w-16` width.
       - Column 2: `#` Index.
       - Column 3: Client / Entity Details.
       - Column 4: GSTIN & State Code with 1-click clipboard copy.
       - Column 5: Filing Frequency badge (`Monthly` vs `QRMP`).
       - Column 6: Compliance Health progress pills (`N/24 Filed` in emerald, `N Overdue` in rose).
       - Column 7: PMT-06 Cash Paid (₹).
       - Column 8: `Track Client →` quick button to jump directly into single-client tracking.
     - Row clickability: Clicking any client row toggles selection; selected rows highlight in purple (`bg-purple-50/80 border-l-4 border-l-purple-600`).
     - Sticky bottom bar: Shows live selected client count and return obligations with primary CTA `Proceed to Compliance Dashboard →`.
