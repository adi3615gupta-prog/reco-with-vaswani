# Plan 19-01: SQLite Allocation Repository, Backend APIs & Zero-Merge Excel Audit Exporter

## Goal
Establish the backend data persistence and export pipeline for the GSTR-3B Inward ITC Allocation Workbench:
1. Initialize SQLite table `gstr3b_itc_allocations` with index and conflict resolution.
2. Implement REST API `GET /api/gstr3b/itc-allocations/:gstin` to fetch GSTR-2B invoices joined with allocations and statutory defaults.
3. Implement REST API `POST /api/gstr3b/itc-allocations` to handle bulk upserts of voucher classifications.
4. Implement REST API `GET /api/gstr3b/export-itc-allocations` generating a multi-sheet, audit-ready Excel workbook strictly enforcing the Zero-Merge architecture (`ws['!merges'] = []`).

---

## Tasks

- [x] **Task 1: SQLite Schema & DB Accessor Functions (`gstr2b/db.js`)**
  - Add `initGstr3bItcAllocations(db)`:
    ```sql
    CREATE TABLE IF NOT EXISTS gstr3b_itc_allocations (
        id TEXT PRIMARY KEY,
        client_gstin TEXT NOT NULL,
        return_period TEXT NOT NULL,
        invoice_id TEXT NOT NULL,
        target_table TEXT NOT NULL,
        notes TEXT,
        allocated_by TEXT DEFAULT 'User',
        created_at INTEGER,
        updated_at INTEGER,
        UNIQUE(client_gstin, return_period, invoice_id)
    );
    CREATE INDEX IF NOT EXISTS idx_gstr3b_itc_alloc_client ON gstr3b_itc_allocations(client_gstin, return_period);
    ```
  - Export `getInvoicesWithAllocations(db, clientGstin, returnPeriod)` returning invoice rows joined with statutory fallback logic.
  - Export `bulkSaveItcAllocations(db, clientGstin, returnPeriod, allocations)` performing batch upsert on conflict.

- [x] **Task 2: REST API Endpoints in `gstr2b_routes.js`**
  - Add `GET /api/gstr3b/itc-allocations/:gstin`:
    - Validates `period` query parameter (supports month names e.g. "June 2025" and 6-digit codes e.g. "062025").
    - Computes aggregated summaries for `eligible_4a5`, `rcm_4a3`, `import_4a1`, `reversal_4b1`, `reversal_4b2`, `ineligible_4d1`, `ineligible_4d2`, and `deferred`.
    - Returns JSON with summary metrics and line-item invoice array.
  - Add `POST /api/gstr3b/itc-allocations`:
    - Accepts array of `{ invoiceId, targetTable, notes }`.
    - Upserts allocations to SQLite and returns recalculated summary.

- [x] **Task 3: Zero-Merge Excel Audit Exporter (`gstr3b_routes` / `gstr2b/itcAuditExcel.js`)**
  - Implement workbook generator containing 5 dedicated tabs:
    1. `Allocation Summary`: Table of 3B fields, invoice counts, taxable values, IGST, CGST, SGST, Cess, Total Tax, and percentage share.
    2. `Eligible ITC 4(A)(5)`: Full voucher register of claimed inward supplies.
    3. `Ineligible Credit 4(D)`: Detailed vouchers blocked under Section 17(5) and Section 16(4) with user audit notes.
    4. `ITC Reversals 4(B)`: Rule 38/42/43 reversed vouchers.
    5. `Deferred Vouchers`: Held vouchers not claimed in current period.
  - Apply `removeAllMergesFromWorkbook(wb)` to guarantee zero `<mergeCell>` entries across all sheets.
  - Stream workbook via `GET /api/gstr3b/export-itc-allocations`.

- [x] **Task 4: Unit / API Verification**
  - Verify query execution with test script.
  - Verify endpoints via `curl` or Node tests.
  - Confirm Zero-Merge compliance on generated Excel buffer.
