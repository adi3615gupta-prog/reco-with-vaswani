# Plan 19-02: In-Place GSTR-3B Inward ITC Allocation & Audit Workbench UI Component

## Goal
Build the comprehensive, responsive React workbench component (`src/components/Gstr3bItcAllocationWorkbench.tsx`) that renders in place of the 3B working table. It allows tax practitioners to inspect, filter, search, and allocate all GSTR-2B inward bills into their statutory GSTR-3B destination fields with real-time KPI metrics and bulk classification controls.

---

## Tasks

- [x] **Task 1: Component Architecture & State Management (`src/components/Gstr3bItcAllocationWorkbench.tsx`)**
  - Define TypeScript interfaces:
    - `Gstr2bInvoiceRow`: ID, Section, CTIN, SupplierName, InvoiceNo, InvoiceDate, InvoiceType, POS, ReverseCharge, ITC_Available, Taxable, IGST, CGST, SGST, Cess, TotalTax, TargetTable, Notes, AllocatedAt.
    - `TargetTableOption`: `'4A5' | '4A3' | '4A1' | '4B1' | '4B2' | '4D1' | '4D2' | 'DEFERRED'`.
    - `AllocationSummary`: Aggregated metrics for each destination field.
  - State:
    - `invoices`: Working list of invoices with current allocations.
    - `searchQuery`: Debounced text filter (GSTIN, supplier name, invoice no).
    - `activeCategoryTab`: `'all' | '4A5' | '4D1' | '4D2' | '4B' | '4A3' | 'DEFERRED'`.
    - `selectedInvoiceIds`: `Set<string>` for multi-select operations.
    - `isSaving`: Loading state for persistence.

- [x] **Task 2: Sticky Top Navigation & KPI Metrics Deck**
  - Header:
    - Active client details (GSTIN, Trade Name).
    - Active Return Period (e.g., June 2025).
    - `← Back to GSTR-3B Working Sheet` return button.
    - `Reconciliation Status` badge: `100% Reconciled (142/142)` in green, or warning badge if any discrepancy exists.
    - `Export Audit Sheet (Excel)` button triggering direct download.
    - `Apply Allocations & Recalculate 3B` action button with gradient accent.
  - KPI Cards:
    - Total 2B Inward Supplies (Vouchers & Tax).
    - Table 4(A)(5) Eligible ITC (Claimed).
    - Table 4(D)(1) Blocked u/s 17(5).
    - Table 4(D)(2) Restricted u/s 16(4) / POS.
    - Table 4(B) Reversals (Rule 38/42/43).
    - Table 4(A)(3) RCM Inward Supplies.
    - Deferred Vouchers (On Hold).

- [x] **Task 3: Statutory Selection Tabs, Search & 1-Click Move Bar**
  - Instant search input with clear button (filters across GSTIN, Legal Name, and Invoice Number).
  - **Statutory Category Tabs (with live bill count & tax amount badges):**
    1. `All Bills (N | ₹X)` — Complete GSTR-2B inward register
    2. `Eligible ITC [4(A)(5)] (N | ₹X)` — Claimed in current month's return (Green badge)
    3. `Ineligible ITC [4(D)] (N | ₹X)` — Blocked u/s 17(5) or time-barred u/s 16(4) (Rose badge)
    4. `Temporary Reversal [4(B)(2)] (N | ₹X)` — Rule 37 (180 days non-payment) / goods not received / reclaimable in future 3B (Indigo badge)
    5. `Permanent Reversal [4(B)(1)] (N | ₹X)` — Rule 38 / 42 / 43 common credit reversals (Amber badge)
    6. `Inward RCM [4(A)(3)] (N | ₹X)` — Reverse charge inward supplies (Purple badge)
    7. `Deferred / Hold (N | ₹X)` — Withheld from current month's filing (Slate badge)
  - **1-Click Bulk Classification Toolbar (visible when $\ge 1$ bill is selected):**
    - "N vouchers selected (₹Y Tax)"
    - `Move to Eligible [4(A)(5)]`
    - `Move to Ineligible [4(D)]`
    - `Move to Temporary Reversal [4(B)(2)]`
    - `Move to Permanent Reversal [4(B)(1)]`
    - `Move to Deferred`
    - `Clear Selection`

- [x] **Task 4: High-Density Voucher Table & Destination Dropdowns**
  - Table Columns:
    1. Checkbox (Select individual / Header select-all).
    2. Section (Badge: B2B, CDNR, B2BA).
    3. Supplier Details (CTIN + Normalized Legal/Trade Name).
    4. Invoice No & Date.
    5. Taxable Value.
    6. CGST / SGST / IGST.
    7. Total Tax.
    8. RCM (`Y` badge / `N`).
    9. Statutory Destination Dropdown (Color-coded badges with 1-click select):
       - `Eligible ITC — 4(A)(5)` (Green)
       - `Ineligible ITC — 4(D)(1) (Sec 17(5) Blocked)` (Rose)
       - `Ineligible ITC — 4(D)(2) (Sec 16(4) Time-Barred)` (Amber)
       - `Temporary Reversal — 4(B)(2) (Reclaimable / Rule 37 / Goods in Transit)` (Indigo)
       - `Permanent Reversal — 4(B)(1) (Rule 38, 42, 43)` (Purple)
       - `Inward RCM — 4(A)(3)` (Blue)
       - `Import of Goods — 4(A)(1)` (Sky)
       - `Deferred / On Hold` (Slate)
    10. Audit Reason / Note (Editable text input with quick-suggest chips:
       - Temporary Reversal chips: "Rule 37 (180 Days Unpaid)", "Goods in Transit / Not Received", "Rate Dispute"
       - Ineligible chips: "Motor Vehicle 17(5)(a)", "Food/Catering 17(5)(b)", "Club Membership 17(5)(b)", "Personal Expense 17(5)(g)", "Time-barred 16(4)")

- [x] **Task 5: Save & Apply Handlers**
  - Local state updates immediately recalculating summary metrics in real-time.
  - "Save Allocations" persists to `POST /api/gstr3b/itc-allocations`.
  - "Apply to 3B Working Sheet" invokes callback `onApplyAllocations(summary, invoices)` passed from parent.
