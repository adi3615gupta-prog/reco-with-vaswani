# Plan 25-03: GSTR-1 Workbench UI, Direct Client Auto-Save & Autonomous Playwright Portal Uploader

## Goal
Build an interactive, high-density GSTR-1 Return Preparation Workbench UI inside Returns & Filing Suite ([`src/components/Gstr1WorkingSheet.tsx`](file:///D:/My%20software/full%20and%20final/gst%20consolidater/reco-with-vaswani-main/src/components/Gstr1WorkingSheet.tsx) & [`src/pages/ReturnsDashboard.tsx`](file:///D:/My%20software/full%20and%20final/gst%20consolidater/reco-with-vaswani-main/src/pages/ReturnsDashboard.tsx)), connecting it with the direct client folder auto-save architecture and providing an autonomous Playwright bot ([`gstr1/autopilot.js`](file:///D:/My%20software/full%20and%20final/gst%20consolidater/reco-with-vaswani-main/gstr1/autopilot.js)) to upload the generated GSTR-1 JSON directly into the GST Portal offline utility screen with a single click.

---

## Tasks

- [ ] **Task 1: Interactive GSTR-1 Preparation & Filing Workbench UI (`src/components/Gstr1WorkingSheet.tsx`)**
  - Create the GSTR-1 Working Sheet component with:
    - **Header KPI Banner:** Total Outward Taxable, IGST, CGST, SGST, Cess, Total Tax, Total Invoices count.
    - **Cross-Reconciliation Strip:** Direct comparison against GSTR-3B Table 3.1(a) Outward Taxable supplies to catch discrepancy before filing.
    - **Section Tabs:**
      - `4. B2B, SEZ, DE` (Filterable invoice list with GSTIN, Buyer, Rate, Taxable, Tax)
      - `5. B2CL (Large)` (> ₹1L Inter-State Unregistered)
      - `7. B2CS (Small)` (Consolidated by POS and Rate)
      - `9B. Credit / Debit Notes` (Registered & Unregistered CDNR)
      - `12. HSN Summary` (With dedicated B2B vs B2C toggle buttons)
      - `13. Documents Issued` (Invoice serial ranges, cancelled, net)
      - `14 & 15. E-Commerce (ECO)` (TCS u/s 52 and supplies u/s 9(5))
    - **Top Action Deck:**
      - `"Save Working Sheet (Ctrl+S)"` (Auto-saves directly to client directory)
      - `"Download GSTR-1 JSON"`
      - `"Export V2.2 Excel Workbook"`
      - `"Export Section-Wise CSVs (ZIP)"`
      - **"Upload JSON directly to Portal"** (Emerald/Teal gradient button with loading state)

- [ ] **Task 2: Returns Dashboard Integration (`src/pages/ReturnsDashboard.tsx`)**
  - Mount `<Gstr1WorkingSheet />` under `activeTab === 'gstr1_downloader'` or provide toggle between Outward 12M Downloader and GSTR-1 Working Sheet.
  - Wire state to active client profile, financial year, and selected return month.
  - Connect `Ctrl+S` hotkey to silent auto-save pipeline.

- [ ] **Task 3: Backend Direct Client Auto-Save Pipeline (`returns_storage_routes.js`)**
  - In `POST /api/returns/save-gstr1-bundle`:
    - Resolve path: `<dataPath>/<Client>/<FY>/<Month>/1 Working/`
    - Write canonical assets:
      - `gstr1_portal_${month}.json`
      - `gstr1_working_${month}.xlsx`
      - `gstr1_v22_${month}.xlsx`
      - `gstr1_data_${month}.json`
    - Trigger Windows toast notification with `"Open Folder"` button.

- [ ] **Task 4: Autonomous Playwright GSTR-1 Portal Uploader (`gstr1/autopilot.js` & `returns_storage_routes.js`)**
  - Implement `runGstr1UploadAutopilot({ db, gstin, month, financialYear, jsonFilePath, jsonContent, browserState })`:
    - Auto-fills credentials from SQLite Vault on the GST Portal login page.
    - Displays assistive user banner during CAPTCHA challenge.
    - Navigates safely via authentic in-page DOM clicks to Returns Dashboard (preventing SSO cross-subdomain Access Denied).
    - Selects Financial Year & Return Period, clicks `SEARCH`.
    - Locates the **GSTR-1 / IFF** tile on the dashboard, clicks **`PREPARE OFFLINE`**.
    - Targets the file upload input (`input[type="file"]`), attaches `gstr1_portal_<month>.json`.
    - Awaits portal validation confirmation ("Your file has been successfully uploaded... Reference ID").
  - Add backend endpoint `POST /api/returns/upload-1-portal` in `returns_storage_routes.js`.
  - Wire frontend button `handleUploadGstr1DirectlyToPortal` in `Gstr1WorkingSheet.tsx`.

- [ ] **Task 5: End-to-End Build & Verification**
  - Run `npm run build` to confirm zero TypeScript compilation errors.
  - Verify route `/api/returns/upload-1-portal` responds with validation checks.
  - Update `ROADMAP.md` and `STATE.md` to reflect Phase 25 progress.
