- [ ] **Task 3: TaxPower Audit Defense Exporters (DRC-01B & DRC-01C)**
  - **DRC-01B Outward Difference Workbook (`CompareGSTR3BWithGSTR1Detailed.xlsx`):**
    - Implement `exportCompareGstr3bWithGstr1Detailed(gstr1Data, gstr3bData, clientProfile)`:
      - Line-by-line comparison across return periods:
        - Line 1: Outward taxable supplies (3B 3.1(a) vs R1 Table 4+5+7+9B)
        - Line 2: Zero-rated / Exports (3B 3.1(b) vs R1 Table 6A)
        - Line 3: Nil/Exempted supplies (3B 3.1(c) vs R1 Table 8)
        - Line 4: Inward RCM supplies (3B 3.1(d) vs R1/2B)
      - Computes Taxable, IGST, CGST, SGST, Cess differences and percentage variance.
      - Highlights rows exceeding the ₹50,000 / 20% threshold triggering statutory DRC-01B notices.
      - Strictly enforces `removeAllMergesFromWorkbook(wb)`.
  - **DRC-01C Inward ITC Scrutiny Workbook (`CompareGSTR3BWithBooksNew.xlsx`):**
    - Implement `exportCompareGstr3bWithBooks(gstr3bData, booksData, clientProfile)`:
      - Compares GSTR-3B Table 4 ITC claimed against Books (Purchase Register):
        - All Other ITC Claimed (3B 4(A)(5) vs Books ITC)
        - RCM ITC Claimed (3B 4(A)(3) vs Books RCM)
        - ITC Reversals (3B 4(B) vs Books Reversals)
      - Explicitly bifurcates:
        - "Excess ITC Claimed in GSTR-3B" $\to$ Immediate DRC-01C recovery notice risk.
        - "Short ITC Claimed in GSTR-3B" $\to$ Unclaimed credit to be availed before Section 16(4) time-barring.
      - Strictly enforces `removeAllMergesFromWorkbook(wb)`.
