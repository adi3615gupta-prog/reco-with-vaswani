  <action>
    1. Define message types in `src/lib/excel/types.ts`:
       - `ExportType = 'MASTER' | 'MONTHLY_COMPARISON' | 'MONTHLY_DIFF' | 'PARTY_WISE' | 'DEBIT_NOTES'`
       - `ExportWorkerRequest = { type: 'EXPORT_WORKBOOK'; exportType: ExportType; payload: any }`
       - `ExportWorkerResponse = { type: 'PROGRESS'; stage: string; currentSheet: number; totalSheets: number; percent: number } | { type: 'SUCCESS'; buffer: ArrayBuffer; filename: string } | { type: 'ERROR'; error: string }`
    2. Implement `src/workers/excelExport.worker.ts`:
       - Setup web worker message event listener listening for `EXPORT_WORKBOOK`.
       - Enable SheetJS Dense Mode: instantiate workbooks with `XLSX.utils.book_new({ dense: true })` and convert row arrays with `XLSX.utils.aoa_to_sheet(rows, { dense: true })` per D-05.
       - Chunked Row Generation: For sheets exceeding 5,000 rows, batch processing in 5,000-row slices to permit V8 garbage collection cycles.
       - Support all 5 export types:
         - `MASTER`: 12-tab master reconciliation workbook (Dashboard, Executive Summary, Monthly Comparison, All Records, Party Summaries, Timing Reco, etc.).
         - `MONTHLY_COMPARISON`: 6-table FY tax matrix (`TABLE_W = 5`, `COLS = 17`).
         - `MONTHLY_DIFF`: 12 individual monthly difference sheets (`April_Diff` to `March_Diff`).
         - `PARTY_WISE`: Vendor party cards and monthly breakdowns.
         - `DEBIT_NOTES`: 21-column standardized debit notes register.
       - Real-time Progress Reporting: Post `{ type: 'PROGRESS', stage, currentSheet, totalSheets, percent }` between sheet generations per D-03.
       - Mandatory Zero-Merge Guard: Systematically invoke `removeAllMergesFromWorkbook(wb)` and `assertZeroMerges(wb)` before writing XLSX.
       - Zero-Copy Transferable Buffer:
         ```ts
         const outputArray = XLSX.write(wb, { bookType: 'xlsx', type: 'array' });
         const arrayBuffer = outputArray.buffer instanceof ArrayBuffer 
           ? outputArray.buffer 
           : new Uint8Array(outputArray).buffer;
         self.postMessage({ type: 'SUCCESS', buffer: arrayBuffer, filename }, [arrayBuffer]);
         ```
       - Error Boundary: Wrap execution in `try / catch` posting `{ type: 'ERROR', error: err.message }` on failures.
  </action>
