# Plan 05-01: Persistent App Shell & Command Navigation

## Overview
Create and mount a persistent, collapsible sidebar and top command bar (`AppShell.tsx`) inside `src/pages/Index.tsx`, wrapping all module routes and enabling seamless navigation without state loss.

## Tasks

### Task 1: Create `src/components/AppShell.tsx`
- **File**: `src/components/AppShell.tsx`
- **Details**:
  - Build collapsible sidebar (`isCollapsed` state with toggle and local storage persistence).
  - Group navigation links into the 5 core suites:
    1. *GST Reco & Audit*: Reconciliation (`reco`), Output Reco, GSTR-2B Tracker (`tracker`).
    2. *Returns & Autopilot*: Returns Dashboard (`returns`), GSTR-2B Autopilot, GSTR-1, IMS.
    3. *Tally Prime & Data*: Tally Direct Import (`tally-direct`), Tally Ledger Import (`ledger-import`), Tally Converter (`tally`).
    4. *TDS, Tax & Statements*: TDS Reconciliation (`tds-reco`), Income Tax Dashboard (`income-tax`), Financial Statements (`fin-statements`).
    5. *Bank CMA & Audit*: Bank CMA Appraisal (`bank-cma`), Tax Audit Clause 44 (`clause44`), Statutory Audit (`audit`), Depreciation (`depreciation`).
  - Add Top Command Bar:
    - Current Active Route title and breadcrumb.
    - Active Company Name & Financial Year selector display.
    - Live System Status HUD: Database SQLite pill (Green), Tally Bridge Port 9000 ping pill (Green/Amber), Localhost status.
    - Command Palette button (`Ctrl+K` shortcut indicator).
  - Implement Command Palette (`CommandDialog` / `cmdk` based) triggered via `Ctrl+K` or clicking search icon for instant keyboard navigation to any module.

### Task 2: Mount `AppShell` in `src/pages/Index.tsx`
- **File**: `src/pages/Index.tsx`
- **Details**:
  - Wrap the main content routing area (`{appRoute === ...}`) inside `<AppShell>`.
  - Maintain the Hub view (`appRoute === 'hub'`) accessible via the logo/Home button.
  - Wire `appRoute` state and `setAppRoute` callback into `AppShell`.
  - Ensure all module props (`mode`, `setMode`, `step`, `setStep`, `results`, `summary`, etc.) remain completely untouched.

## Verification
- `npx tsc --noEmit` returns 0 type errors.
- Vitest tests pass: `npm test`.
- All routes render inside the shell with functional sidebar navigation.
