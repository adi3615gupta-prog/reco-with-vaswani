<threat_model>
<threat>
  <id>T-33-01</id>
  <description>XML Injection vulnerability: Malicious or unescaped characters in ledger names, narrations, or invoice numbers breaking the XML structure or corrupting Tally database during import.</description>
  <mitigation>All user-supplied strings are sanitized through a strict `escapeXml()` utility converting `&` to `&amp;`, `<` to `&lt;`, `>` to `&gt;`, `"` to `&quot;`, and `'` to `&apos;` prior to XML node insertion.</mitigation>
</threat>
<threat>
  <id>T-33-02</id>
  <description>Unbalanced Voucher Generation: Generating XML for multi-ledger vouchers where debits and credits do not balance, leading to corrupted vouchers or Tally import errors.</description>
  <mitigation>The engine strictly calculates `checkTotal` for every voucher. XML generation rejects unbalanced vouchers unless explicitly balanced via `autoBalanceMultiEntry()`.</mitigation>
</threat>
</threat_model>
