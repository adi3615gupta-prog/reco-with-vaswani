<threat>
  <id>T-37-01</id>
  <description>Unauthenticated access to 25+ endpoints across returns, tax, notices, TDS, audit storage, GDrive backups, and Tally Port 9000 XML proxy.</description>
  <mitigation>Migrate all frontend callers to `safeApiFetch`/`authHeaders()`, pass and enforce `authenticateToken` across all 6 unauthenticated route modules + `/api/tally-proxy` + `/api/gdrive/*`, leaving only an explicit minimal public whitelist.</mitigation>
</threat>
<threat>
  <id>T-37-02</id>
  <description>Privilege escalation via client-side `localStorage.setItem('np_admin', 'true')`, unauthenticated `/api/reset-license`, and missing `req.user.role === 'admin'` checks on `/ban` and `/api/gdrive/*`.</description>
  <mitigation>Verify `req.user.role === 'admin'` on all admin endpoints, require verified admin password or admin JWT on `/api/reset-license`, and source UI admin state from signed JWT / `/api/me` verification.</mitigation>
</threat>
<threat>
  <id>T-37-03</id>
  <description>Renderer XSS escalating to arbitrary Electron main-process IPC via `window.electronAPI.invoke` and loopback SSRF port scanning via `fetch_tally_data`.</description>
  <mitigation>Remove generic `invoke` from `preload.js` (expose only explicit typed IPC methods) and restrict `fetch_tally_data` ports in `main.cjs` to `9000–9010`.</mitigation>
</threat>
</threat_model>
