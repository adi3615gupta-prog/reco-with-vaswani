# Plan 20-01: Direct Client Folder Silent Auto-Save & Structured Subfolder Hierarchy Base Pipeline

## Goal
Decouple client-side browser file downloads from the GSTR-3B Working Sheet and Returns Dashboard manual save pipeline (`handleManualSave()` and `Ctrl+S`). Ensure clicking "Save Working Sheet" (or pressing `Ctrl+S`) writes all 4 assets (date-wise & latest Excel workbook, PDF statement, GSTN portal JSON payload, and full working data) as well as all 4 statutory base schedules (R1 Base, 2B Base, Credit Notes Base, Reversal Base) directly and silently into structured subfolders under the client's respective directory structure on the local disk/server (`gst_returns_data/<Client>/<FY>/<Month>/3B Working/`) without triggering browser file prompts ("Where do you want to save this file?"), while preserving explicit manual download actions for ad-hoc user requests.

---

## Tasks

- [x] **Task 1: Decouple Browser Downloads in `handleManualSave()` (`src/pages/ReturnsDashboard.tsx`)**
  - In `handleManualSave()`:
    - Retain Excel workbook blob generation and Base64 conversion (`generateGstr3bWorkingExcel` -> `blobToBase64`).
    - Remove the synthetic `<a>` download trigger (`excelA.download`, `excelA.click()`, `document.body.appendChild/removeChild`).
    - Pass `autoDownload: false` to `exportGstr3bMonthPdf(...)` so that `doc.save(...)` is bypassed, while `pdfResult.base64` is preserved.
    - Retain GSTN Portal JSON generation and parsing (`generateGstr3bPortalJson`), but remove the synthetic `<a>` download trigger (`jsonA.download`, `jsonA.click()`).
    - Send `excelBase64`, `pdfBase64`, `portalJsonData`, `workingData`, and metadata to `POST /api/returns/save-full-bundle`.
    - Retain `saveClientWorkingData(workingData)` to ensure `localStorage` and SQLite stay synchronized.

- [x] **Task 2: Backend Structured Subfolder Hierarchy & Base Generators (`returns_storage_routes.js`)**
  - Update `POST /api/returns/save-full-bundle`:
    - Resolve the month path: `mDir = path.join(fyDir, mFolderName)`
    - Create parent folder: `monthWorkingDir = path.join(mDir, '3B Working')`
    - Create and populate the 5 statutory subfolders:
      1. **`3B Working/`**:
         - `${safeFirm} - GSTR-3B Working ${monthClean}_${dateTimeStamp}.xlsx` + `gstr3b_working_${monthClean}.xlsx`
         - `${safeFirm} - GSTR-3B Working ${monthClean}_${dateTimeStamp}.pdf` + `gstr3b_working_${monthClean}.pdf`
         - `${safeFirm} - GSTR-3B Portal Upload ${monthClean}_${dateTimeStamp}.json` + `gstr3b_portal_${monthClean}.json`
         - `${safeFirm} - GSTR-3B Data ${monthClean}_${dateTimeStamp}.json` + `gstr3b_data_${monthClean}.json`
      2. **`R1 Base/`**:
         - Query `gstr1_invoices` for `gstinClean` & return period (or generate from `workingData.months[m].outward`).
         - Write `<safeFirm> - GSTR-1 Outward Base ${monthClean}_${dateTimeStamp}.xlsx` (B2B, B2C, SEZ, Advances, Nil/Exempt) and `gstr1_base_${monthClean}.json`.
      3. **`2B Base/`**:
         - Query `gstr2b_invoices` for `gstinClean` & return period.
         - Write `<safeFirm> - GSTR-2B Inward Base ${monthClean}_${dateTimeStamp}.xlsx` (B2B, B2BA, Inward RCM) and `gstr2b_base_${monthClean}.json`.
      4. **`Credit Notes Base/`**:
         - Query CDNR outward & inward credit/debit notes from `gstr1_invoices` and `gstr2b_invoices`.
         - Write `<safeFirm> - Credit Notes Register ${monthClean}_${dateTimeStamp}.xlsx` and `credit_notes_base_${monthClean}.json`.
      5. **`Reversal Base/`**:
         - Query `gstr3b_itc_allocations` for `reversal_4b1`, `reversal_4b2`, `ineligible_4d1`, `ineligible_4d2`, and `deferred` bills (or generate from `workingData.months[m].inward`).
         - Write `<safeFirm> - ITC Reversals & Ineligible Schedule ${monthClean}_${dateTimeStamp}.xlsx` and `reversal_base_${monthClean}.json`.
    - Maintain root month backward compatibility copies (`gstr3b_working_${monthClean}.xlsx`, `working.json`, etc.) in `mDir` so existing readers continue working seamlessly.
    - Return `monthWorkingDir`, `monthDir`, and subfolder stats in the JSON response.

- [x] **Task 3: Refine Success Toast Notification & Native Folder Launcher (`src/pages/ReturnsDashboard.tsx`)**
  - Update the response handler for `POST /api/returns/save-full-bundle`:
    - Display toast: `"Saved directly to Client Folder (All 5 Bases)!"`.
    - Include clean folder path in description: `"Saved to: gst_returns_data/<Client>/<FY>/<Month>/3B Working/ (All 5 Bases)"`.
    - Provide interactive action button: `"Open Folder"` calling `POST /api/returns/open-folder` with `resData.monthWorkingDir || resData.monthDir` to reveal the exact directory in Windows Explorer.
    - Ensure zero browser download prompts occur when clicking "Save Working Sheet" or pressing `Ctrl+S`.

- [x] **Task 4: Build & Invariant Scrutiny**
  - Verify explicit manual download buttons ("Download GSTR-3B Working Excel", "Print Official PDF", "Generate GSTN Portal JSON") still trigger browser downloads when explicitly clicked.
  - Run full TypeScript compilation (`npm run build`) to ensure 0 build errors.
