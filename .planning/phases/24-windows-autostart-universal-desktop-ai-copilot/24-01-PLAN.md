# PLAN: 24-01 — Electron Core Lifecycle, Background Auto-Startup & System Tray Hub

**Phase:** 24 — Windows Background Auto-Start & Universal Desktop AI Copilot (PC Loco Pilot)  
**Plan:** 24-01  
**Status:** 📋 Ready  
**Goal:** Implement silent Windows auto-startup on boot, System Tray presence with context menu controls, close-to-tray lifecycle protection, and auto-start toggle IPC.

---

## Tracer Slice (Ship First)
**Tracer:** A persistent Windows System Tray icon (`Tray`) with context menu ("Open App", "Toggle Sourav Copilot", "Auto-Start with Windows", "Quit") and `mainWindow.on('close')` intercepted to minimize-to-tray, keeping the Express backend server running indefinitely in the background.

---

## Tasks

### T1 — Single-Instance Lock Hardening
- **File:** `main.cjs`
- **Action:** Ensure `app.requestSingleInstanceLock()` focuses the existing `mainWindow` if user tries to open a second instance while running in tray.
- **Verify:** Launching a second instance restores and focuses the existing window.

### T2 — System Tray (`Tray`) Implementation
- **File:** `main.cjs`
- **Action:**
  - Create `tray = new Tray(iconPath)`.
  - Set tooltip: `AUDIT WITH VASWANI — Enterprise Compliance & Sourav AI`.
  - Build context menu (`Menu.buildFromTemplate`):
    - `Open AUDIT WITH VASWANI` $\to$ `mainWindow.show(); mainWindow.focus();`
    - `Toggle Sourav AI Copilot` $\to$ `toggleCopilotWindow();`
    - `Start with Windows` $\to$ Checkbox reflecting `app.getLoginItemSettings().openAtLogin`
    - `---` (Separator)
    - `Quit Completely` $\to$ `app.isQuitting = true; app.quit();`
  - Double-click on tray icon toggles `mainWindow`.

### T3 — Window Close Interception (Minimize-to-Tray)
- **File:** `main.cjs`
- **Action:**
  - Set `app.isQuitting = false;`.
  - In `mainWindow.on('close', (event) => ...)`:
    - If `!app.isQuitting`, `event.preventDefault(); mainWindow.hide();`.
  - Display balloon notification on first minimize explaining the app is running in the background tray.

### T4 — Windows Auto-Startup API & CLI Detection
- **File:** `main.cjs`, `preload.js`
- **Action:**
  - Detect `--hidden` in `process.argv` or `app.getLoginItemSettings().wasOpenedAsHidden`.
  - If launched hidden on Windows boot: do not call `mainWindow.show()`; only initialize backend and tray.
  - Implement IPC handlers:
    - `get_startup_settings` $\to$ returns `{ openAtLogin, openAsHidden }`.
    - `set_startup_settings` $\to$ calls `app.setLoginItemSettings({ openAtLogin, openAsHidden: true, args: ['--hidden'] })`.
  - Expose in `preload.js`.
