# PLAN: 24-02 — Universal Always-On-Top Floating Desktop Copilot Window & Global Hotkey

**Phase:** 24 — Windows Background Auto-Start & Universal Desktop AI Copilot (PC Loco Pilot)  
**Plan:** 24-02  
**Status:** 📋 Ready  
**Goal:** Create a dedicated secondary transparent, frameless, always-on-top BrowserWindow for Sourav AI that floats over any application (Excel, Tally, Chrome, Desktop), register global hotkeys, and implement dynamic bounds resizing between collapsed orb and expanded chat states.

---

## Tracer Slice (Ship First)
**Tracer:** A secondary frameless transparent window (`copilotWindow`) that floats in the bottom-right corner of the desktop, remains visible when `mainWindow` is minimized, responds to the global shortcut `Ctrl+Alt+S`, and resizes dynamically between compact orb (64x64) and expanded card (420x640).

---

## Tasks

### T1 — Dedicated `copilotWindow` BrowserWindow Creation
- **File:** `main.cjs`
- **Action:**
  - Create `copilotWindow = new BrowserWindow({ ... })`:
    - `width: 64, height: 64`
    - `frame: false, transparent: true, alwaysOnTop: true`
    - `skipTaskbar: true, resizable: false, focusable: true`
    - Position near bottom-right of primary display work area (`screen.getPrimaryDisplay().workAreaSize`).
  - Load `http://localhost:${BACKEND_PORT}/#/copilot-desktop` (or local file in packaged build).

### T2 — Dynamic Bounds Resizing via IPC (`resize_copilot`)
- **File:** `main.cjs`, `preload.js`
- **Action:**
  - Handle `resize_copilot` IPC event:
    - If `expanded: true`: set bounds to `width: 420, height: 640`, repositioned to anchor at bottom-right corner.
    - If `expanded: false`: set bounds to `width: 64, height: 64`, repositioned to anchor at bottom-right orb position.
  - Expose `resizeCopilot(expanded)` in `preload.js`.

### T3 — Global Hotkey (`globalShortcut`) Registration
- **File:** `main.cjs`
- **Action:**
  - Register `CommandOrControl+Alt+S` using `globalShortcut.register`.
  - On trigger:
    - If `copilotWindow` is hidden or collapsed: expand and focus.
    - If `copilotWindow` is open and focused: collapse or hide.
  - Safely unregister on app quit (`app.on('will-quit')`).
