### T2 — Bidirectional IPC Bridge (`navigate_app` & `app_navigate`)
- **File:** `main.cjs`, `preload.js`, `src/components/SouravChatbot.tsx`, `src/pages/Index.tsx`
- **Action:**
  - In `main.cjs`:
    ```javascript
    ipcMain.on('navigate_app', (_event, { target, gstin }) => {
      if (mainWindow) {
        if (mainWindow.isMinimized()) mainWindow.restore();
        mainWindow.show();
        mainWindow.focus();
        mainWindow.webContents.send('app_navigate', { target, gstin });
      }
    });
    ```
  - In `preload.js`: Expose `navigateApp(data)` and `onAppNavigate(callback)`.
  - In `AppShell.tsx` / `Index.tsx`: Handle `app_navigate` by switching to target module and auto-selecting the client from the hub directory.

  - Bind to `electronAPI.invoke('set_startup_settings', enabled)`.
