# Roadmap: Vaswani Return Enterprise (Audit With Vaswani)

## Overview

Vaswani Return Enterprise is an enterprise-grade desktop and LAN-enabled tax compliance, audit scrutiny, and reconciliation platform designed for Chartered Accountants, Tax Consultants, and Corporate Accounts Teams.
