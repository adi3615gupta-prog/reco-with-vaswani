## 3. Cross-Phase Integration & End-to-End User Flows

1. **Flow 1: Books vs 2B Inward Reconciliation & Zero-Merge Export**
   - Ingest Tally XML vouchers or Purchase Register via worker-offloaded parser.
   - Run multi-pass waterfall matching with tolerance, core serial stripping, and standalone debit note reconciliation.
   - Generates 12-tab zero-merge workbook (`ws['!merges'] = []`) with complete formulas and formatting.
2. **Flow 2: 1-Login 12-Month GSTR-2B Autopilot & Full-Year Consolidation**
   - Launches Chrome, executes single CAPTCHA verification, loops April through March.
   - Preserves existing data on network timeouts (Golden Rule).
   - Generates 8-sheet consolidated SectionWiseSummary Excel workbook with side-by-side matrices.
3. **Flow 3: GSTR-3B Working Sheet & Table 4 ITC Allocation Workbench**
   - Table 4 interactive drill-down switches into underlying 2B voucher allocation register.
   - Real-time recalculation of Table 4 eligible/ineligible figures and Rule 88A set-off cascade.
   - Unutilized cash credits roll over (`surplusTdsCashCfNextMonth`) into subsequent return months.
4. **Flow 4: GST Notices Autonomous Suite & Courtroom Legal Reply Engine**
   - Playwright scraper downloads notices and DRC attachments into SQLite database.
   - Limitation calendar tracks 7-day and 30-day statutory hearing deadlines.
   - Zero-Trust PII Sanitizer strips GSTINs/PANs/names before sending prompts to Gemini.
   - Generates structured ASMT-11 / DRC-06 legal replies with statutory citations.
5. **Flow 5: Financial Statements Engine (Schedule III Corporate & Non-Corporate ICAI 2022)**
   - Ingests Trial Balance with automated 4-digit taxonomy mapping (1001 to 4902).
   - Computes Balance Sheet, Profit & Loss, AS-3 Indirect Cash Flow Statement, and MCA 2021 disclosures.
   - Evaluates 35+ Internal Financial Control (IFC) preventive rules in real time.
6. **Flow 6: Universal Desktop AI Copilot (Loco Pilot)**
   - Windows startup initiates silent background tray execution.
   - Global hotkey (`Ctrl+Alt+S`) summons always-on-top transparent copilot window over external applications.
   - Interactive action buttons focus main app, switch active client, and navigate to target suites.
